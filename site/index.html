norph

Text that morphs into its next value. Shared letters slide, new ones fade in, and digits roll by place value. One Reanimated component for iOS, Android, and web.

Get started GitHub

Press a chip again to step it, or type in the field.

Install

In an Expo app:

npx expo install norph react-native-reanimated react-native-worklets

norph ships TypeScript source for Metro, so it needs no native build of its own.

Use

import { MorphText } from 'norph';

<MorphText style={{ fontSize: 24, alignSelf: 'flex-start' }}>
  {count}
</MorphText>
children
The text, a string or a number. A change morphs in place.
style
Text styles reach every glyph. Margins and alignment reach the outer box.
className
The same split, for apps that resolve classes on core components, such as Uniwind.
numberOfLines
Turns the morph off and renders plain text.

Behavior

  • The first render does not animate. At rest, the text is one plain Text.
  • Numbers match digits by place value and align on the decimal point, so 99 to 100 rolls every digit and 1.5 to 12.5 keeps the point.
  • Reduced motion swaps the text with no animation. Screen readers read the whole string once.
  • One line. It does not wrap while it morphs.
